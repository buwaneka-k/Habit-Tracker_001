What to build
A small frontend-only habit tracker: a few daily habits, ticked off day by day, with a month view and a small stats screen. Mock data only, no backend, no login, no roles, single user. The app itself doesn't need to look nice — we're checking how you set up the project for AI-assisted work and how you drive Claude through the day, not the UI.
Rule: the app shows how many days in a row a habit was done, and a future day can't be ticked.
